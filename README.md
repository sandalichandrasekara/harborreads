# HarborReads: Personalized Book Recommendation System

**HarborReads** is a feature-rich, web-based platform designed to solve the user cold-start problem in book recommendation systems by combining conversational AI with tailored content-based filtering.

</div>

---

## **Description**

HarborReads is an intelligent web application developed to provide hyper-personalized book recommendations, specifically targeting new users who lack historical reading data (the cold-start problem). By integrating an **NLP-powered chatbot** driven by a fine-tuned **GPT-3.5** model, the platform engages users in natural conversations to seamlessly extract their reading preferences, favorite genres, and stylistic tastes. 

Beyond recommendations, HarborReads offers an all-in-one literary workspace equipped with personal library tracking, insightful reading analytics, and interactive tools to elevate the reading journey.

---

## **Key Features**

* **Conversational Preference Discovery:** Overcomes the cold-start problem using a fine-tuned GPT-3.5 chatbot that intelligently interprets user preferences through natural dialogue.
* **Content-Based Filtering:** Delivers accurate, customized book recommendations matching individual user profiles.
* **Personal Library Tracking:** Empowers users to organize, manage, and track their digital bookshelves effortlessly.
* **Reading Insights & Analytics:** Visualizes reading habits, progress, and milestones to keep users motivated.
* **Interactive Engagement Tools:** Fosters a dynamic environment for new readers to explore and interact with literary content.

---

## **Tech Stack**

* **Artificial Intelligence & NLP:** OpenAI GPT-3.5 (Fine-tuned), Natural Language Processing
* **Recommendation Engine:** Content-Based Filtering Algorithms
* **Application Type:** Web Application
